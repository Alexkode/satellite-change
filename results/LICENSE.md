The original OSCD archive README identifies imagery as modified Copernicus Sentinel data from 2015–2018 and releases change labels under Creative Commons BY-NC-SA, without specifying a version. These terms cover the corresponding derived examples and are separate from the repository's MIT code license. The authors request contact for commercial use of change labels.

Attribution: Rodrigo Caye Daudt, Bertrand Le Saux, Alexandre Boulch and Yann Gousseau. Urban Change Detection for Multispectral Earth Observation Using Convolutional Neural Networks. IGARSS 2018, pp. 2115–2118.
